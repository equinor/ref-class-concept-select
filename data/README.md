# data

Shared, versioned data. Raw data is not here; it stays in `$VOLVE_DATA`
(default `../volve_data`). Rules are in `agents/sys/GUIDELINES.md` §2, §3
and §5.

| Path | Content | Maintained with |
|---|---|---|
| `manifest.csv` | Path, size and SHA-256 of every file in `$VOLVE_DATA`: the raw files and the four generated `_FLOW` deck files | `make manifest`, `make manifest-verify`; `make flow-deck` regenerates the `_FLOW` files |
| `sources.csv` | Source IDs used in provenance fields | By hand |
| `sodir/<YYYYMMDD>/` | Snapshot of the Sodir FactPages tables for all fields, with `index.csv` | `make sodir` |
| `npd_archive/` | Internet Archive captures of NPD FactPages pages and tables for Volve, unchanged, with `index.csv` | By hand; recipe in `docs/data-sources.md` |
| `facts/<source-id>.csv` | Fact register, one row per value | `make facts-validate`; `facts/sodir.csv` is generated by `make facts` |
| `volve/` | Converted documents (`md/`) and figure cut-outs (`figs/`), mirroring the folders of `$VOLVE_DATA` | doc |

The Sodir CSV files are stored exactly as downloaded; they start with a UTF-8
byte-order mark, so read them with the `utf-8-sig` encoding or
`syskit.sodir.read_table`.
